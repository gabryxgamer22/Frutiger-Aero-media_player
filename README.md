# Frutiger-Aero-media_player
An .MP3/.WAV file player inspired by the Frutiger Aero design. There are a ready-to-use Windows .exe file, other miscellaneous files like mp3, png, ico. Please report any unexpected behavior or bugs or suggestions for improvement in the "Issues" section. This is my first coding project, so it won't be perfect. Thanks for supporting the project.
